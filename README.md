# Room Nine Website Prototype — Revision 02

## Test locally

1. Open this folder.
2. Double-click `index.html`.
3. If your browser blocks local assets, run this folder through a local server:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.
